## Общая информация

Базовый URL: `http://localhost:8080`

Формат ответа:
- Успешный ответ: `{"status": "success", "data": { ... }}`
- Ответ с ошибкой: `{"status": "error", "message": "Описание ошибки"}`

Заголовки для всех запросов:
- `Content-Type: application/json`
- Для защищенных эндпоинтов: `Authorization: Bearer {JWT-токен}`
