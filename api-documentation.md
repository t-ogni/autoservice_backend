## Аутентификация

### Регистрация нового пользователя
**Запрос:**
```

POST /register
```
**Заголовки запроса:**
- Content-Type: application/json

**Тело запроса:**
```json
{
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "password": "securePassword123",
  "phone": "+7 999 123 45 67"
}
```


**Ответ:**
- Код статуса: 200 OK
- Формат данных: JSON

**Структура ответа:**
```json
{
  "status": "success",
  "data": {
    "token": "jwt-token-string",
    "userId": 1,
    "role": "user"
  }
}
```


**Ошибки:**
- 400 Bad Request - если тело запроса некорректно
- 409 Conflict - если пользователь с таким email уже существует
- 500 Internal Server Error - в случае ошибки сервера
